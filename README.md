A one-line roast of a smart fridge, framed as its annual performance review, in 126 characters: flawless at staying cold, two strikes on milk expiry, and it still lists a firmware update as "personal growth" — no raise. The program writes the line to `/output/entry.txt` — deterministic, Node stdlib only, no network.

## Run it

```sh
node main.ts
```
